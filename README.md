# Elementor to Bale

اتصال فرم‌های **Elementor Pro** به ربات **Bale Messenger** برای دریافت خودکار اطلاعات فرم در بله.

این پروژه یک افزونه وردپرس است که داده‌های ارسال‌شده از فرم Elementor Pro را از طریق Webhook دریافت می‌کند و با استفاده از API بله، پیام را برای یک یا چند `Chat ID` ارسال می‌کند.

> وضعیت پروژه: نسخه `1.1.0`

## ✨ امکانات

- اتصال فرم Elementor Pro به ربات بله
- دریافت اطلاعات فرم از طریق Webhook
- ارسال خودکار اطلاعات فرم به یک یا چند Chat ID
- امکان تنظیم چند Chat ID
- امکان تعیین عنوان پیام‌های دریافتی
- تولید خودکار کلید امنیتی برای Webhook
- امکان ساخت مجدد کلید امنیتی در صورت افشای کلید قبلی
- ارسال پیام تست به Chat IDهای تنظیم‌شده
- بررسی صحت Bot Token با متد `getMe`
- بررسی وضعیت Webhook با `getWebhookInfo`
- تنظیم و حذف Webhook دریافتی بله برای تست
- تست ارسال پیام `/start` از بله به سایت
- ثبت لاگ ۵۰ ارسال اخیر فرم
- نمایش وضعیت موفق یا ناموفق بودن ارسال به بله
- پشتیبانی از داده‌های JSON و پارامترهای معمول Webhook
- تبدیل مقادیر آرایه‌ای فرم به متن قابل نمایش

## 🧩 پیش‌نیازها

- WordPress
- Elementor Pro
- یک Bot در Bale
- Bot Token
- حداقل یک Chat ID
- فعال بودن REST API وردپرس
- دسترسی سرور وردپرس به اینترنت برای ارسال درخواست به API بله

فرم Elementor باید قابلیت **Webhook** را داشته باشد؛ بنابراین این پروژه برای استفاده اصلی به Elementor Pro نیاز دارد.

## 📦 نصب

### روش ۱: نصب دستی

1. فایل `elementor-to-bale.php` را دانلود کنید.
2. یک پوشه با نام زیر بسازید:

```text
elementor-to-bale
```

3. فایل PHP را داخل آن قرار دهید.
4. پوشه را ZIP کنید.
5. در پیشخوان وردپرس به مسیر زیر بروید:

```text
افزونه‌ها → افزودن افزونه → بارگذاری افزونه
```

6. فایل ZIP را نصب و فعال کنید.

### روش ۲: نصب از GitHub

مخزن پروژه:

https://github.com/amir-shabani12/elementor-to-bale

پس از دریافت پروژه، فایل `elementor-to-bale.php` را در پوشه افزونه‌های وردپرس قرار دهید:

```text
wp-content/plugins/elementor-to-bale/
```

سپس افزونه را از پیشخوان وردپرس فعال کنید.

## ⚙️ تنظیمات

بعد از فعال‌سازی افزونه، از پیشخوان وردپرس وارد مسیر زیر شوید:

```text
تنظیمات → اتصال به بله
```

در این صفحه موارد زیر را وارد کنید:

### Bot Token

توکن ربات بله را وارد کنید.

```text
YOUR_BOT_TOKEN
```

### Chat ID

شناسه چت مقصد را وارد کنید.

می‌توانید چند Chat ID داشته باشید؛ هر شناسه را در یک خط یا با کاما جدا کنید:

```text
123456789
987654321
```

در این حالت پیام فرم برای تمام Chat IDهای واردشده ارسال می‌شود.

### عنوان پیام

عنوانی که در ابتدای پیام فرم نمایش داده می‌شود.

مثلاً:

```text
یک فرم جدید ارسال شد
```

## 🔗 اتصال Elementor به بله

بعد از ذخیره تنظیمات، افزونه یک Webhook اختصاصی ایجاد می‌کند.

آدرس نمایش داده‌شده در صفحه تنظیمات را کپی کنید.

سپس در فرم Elementor Pro به مسیر زیر بروید:

```text
Form
→ Actions After Submit
→ Webhook
```

آدرس Webhook افزونه را در تنظیمات Webhook قرار دهید.

ساختار آدرس به شکل زیر است:

```text
https://example.com/wp-json/bale-notifier/v1/webhook?key=YOUR_SECRET_KEY
```

کلید امنیتی باعث می‌شود درخواست‌های Webhook بدون کلید معتبر پذیرفته نشوند.

## 📩 نمونه پیام

اگر فرم دارای فیلدهای زیر باشد:

```text
name
phone
message
```

پیام ارسالی می‌تواند به شکل زیر باشد:

```text
📩 یک فرم جدید ارسال شد
🌐 سایت: example.com
🕒 زمان: 2026-09-04 20:30:00
--------------------
name: Amir
phone: 09120000000
message: درخواست مشاوره
```

نام فیلدها همان نام‌هایی هستند که Elementor در داده Webhook ارسال می‌کند.

## 🧪 تست اتصال

افزونه چند ابزار برای عیب‌یابی در اختیار شما قرار می‌دهد.

### 1. بررسی Token

با `getMe` می‌توان بررسی کرد که Bot Token معتبر است یا خیر.

### 2. بررسی Webhook

با `getWebhookInfo` می‌توان وضعیت Webhook فعلی ربات را مشاهده کرد.

### 3. تنظیم Webhook دریافتی

برای تست ارتباط دوطرفه، افزونه می‌تواند Webhook زیر را برای بله تنظیم کند:

```text
/wp-json/bale-notifier/v1/bot-incoming
```

بعد از تنظیم آن، به ربات در بله پیام زیر را ارسال کنید:

```text
/start
```

در صورت درست بودن ارتباط، ربات Chat ID شما را برمی‌گرداند.

### 4. حذف Webhook تست

بعد از پایان تست Webhook دریافتی، آن را حذف کنید؛ چون ارسال فرم Elementor به Webhook دریافتی بله وابسته نیست.

> **هشدار:** اگر همین Bot Token قبلاً برای ربات دیگری استفاده شده و آن ربات Webhook فعال دارد، تنظیم Webhook جدید می‌تواند Webhook قبلی را جایگزین کند.

### 5. ارسال پیام تست

با دکمه ارسال پیام تست می‌توانید بدون ارسال فرم Elementor، ارتباط سایت با API بله را بررسی کنید.

## 🔐 امنیت

برای Webhook فرم Elementor یک کلید امنیتی تصادفی ایجاد می‌شود.

درخواست بدون کلید معتبر با خطای HTTP `403` رد می‌شود.

اگر احتمال می‌دهید URL یا کلید Webhook افشا شده است، از بخش تنظیمات گزینه ساخت کلید جدید را فعال کنید.

پس از تولید کلید جدید، URL Webhook قبلی دیگر معتبر نخواهد بود و باید URL جدید را در Elementor قرار دهید.

## 📝 لاگ ارسال‌ها

افزونه آخرین ارسال‌های فرم را در تنظیمات خود ذخیره می‌کند.

حداکثر:

```text
50 ارسال اخیر
```

برای هر ارسال موارد زیر ثبت می‌شود:

- تاریخ و زمان
- متن پیام
- وضعیت ارسال
- متن خطا در صورت ناموفق بودن

## 🔌 REST API

افزونه دو Endpoint ایجاد می‌کند.

### Webhook فرم Elementor

```http
POST /wp-json/bale-notifier/v1/webhook
```

این Endpoint داده فرم را دریافت کرده و پس از اعتبارسنجی کلید امنیتی، آن را برای Chat IDهای تنظیم‌شده ارسال می‌کند.

### Webhook دریافتی بله

```http
POST /wp-json/bale-notifier/v1/bot-incoming
```

این Endpoint برای تست ارتباط ورودی ربات استفاده می‌شود و کاربرد اصلی افزونه نیست.

## 🌐 API بله

ارتباط با API ربات بله از طریق Endpointهای `tapi.bale.ai` انجام می‌شود.

از متدهای زیر در پروژه استفاده شده است:

- `sendMessage`
- `getMe`
- `getWebhookInfo`
- `setWebhook`

## 🛠️ عیب‌یابی

اگر پیام فرم به بله ارسال نمی‌شود، این موارد را به ترتیب بررسی کنید:

### Token

از گزینه:

```text
بررسی صحت توکن (getMe)
```

استفاده کنید.

### Chat ID

مطمئن شوید Chat ID صحیح است و ربات امکان ارسال پیام به آن مقصد را دارد.

### Webhook Elementor

بررسی کنید URL را دقیقاً از صفحه تنظیمات افزونه کپی کرده باشید.

### REST API

مطمئن شوید REST API وردپرس روی سایت مسدود نشده باشد.

### اتصال سرور

سرور وردپرس باید بتواند به API بله درخواست HTTPS ارسال کند.

### لاگ افزونه

بخش:

```text
لاگ آخرین ارسال‌های فرم
```

را بررسی کنید. در صورت خطا، پیام خطا در همین بخش نمایش داده می‌شود.
